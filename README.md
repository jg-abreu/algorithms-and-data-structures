LeetCode submissions are synced here by [LeetHub v2](https://github.com/arunbhardwaj/LeetHub-2.0). The study goals and introductory sections of this README are maintained manually.

## 🎯 Goals

- Build a **consistent practice habit** — a little every day beats a lot once in a while.
- Learn to recognize **common patterns** (hashing, two pointers, sliding window, etc.) instead of memorizing answers.
- Always start with a **brute-force solution**, then look for a better one.
- Prepare for **technical interviews** and coding assessments.
- Gradually build a foundation for **competitive programming** with C++.

## 📁 Repository Structure

Planned organization for LeetCode practice, independent C++ studies and future competitive programming solutions:

```text
algorithms-and-data-structures/
├── README.md
├── .gitignore
├── leetcode/
│   ├── README.md
│   ├── stats.json
│   └── <problem-id>-<problem-name>/
│       ├── README.md
│       ├── <problem-id>-<problem-name>.java
│       └── <problem-id>-<problem-name>.py
├── cpp/
│   └── <course-topic>/
│       └── <exercise>.cpp
├── cses/
│   └── <category>/
│       └── <problem>.cpp
├── codeforces/
│   └── <contest-id>/
│       └── <problem-letter>.cpp
└── atcoder/
    └── <contest-id>/
        └── <problem-letter>.cpp
```

- **leetcode/** — LeetCode solutions, primarily in Java, with earlier Python solutions preserved where available.
- **cpp/** — independent C++ course exercises, organized by topic.
- **cses/**, **codeforces/** and **atcoder/** — future competitive programming solutions, added as those stages begin.

This structure is planned and has not yet been applied. Existing LeetCode folders remain at the root until the LeetHub destination configuration is checked. NeetCode is a learning resource; solutions stay with their original platform.
